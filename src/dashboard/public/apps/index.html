How upload-bugs works

  1. Open an app from the grid above — all four open the same Workspace, scoped to that app's data.
  2. Use the app pill in the top-right to hop between Workspace / Tawazon / Droop / QuickIn without re-typing the URL.
  3. Pick a sheet from the hub (Web / Mobile / Backend / Designs / …).
  4. Click + Add on the sheet, fill the title + description + priority + criteria, save. Drag-drop screenshots in the issue card.
  5. Keys are scoped per app: a Tawazon-only key cannot edit Workspace. * grants every app.
