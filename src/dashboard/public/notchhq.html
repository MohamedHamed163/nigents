Install

Get Started

Up and running in under a minute

Quick Install

# 1. Open the DMG and drag to Applications
$ open NotchHQ.dmg

# 2. Fix quarantine (unsigned build)
$ xattr -cr /Applications/NotchHQ.app

# 3. Ad-hoc re-sign the app
$ codesign --force --deep --sign - /Applications/NotchHQ.app

# 4. Launch!
$ open /Applications/NotchHQ.app

Hover your mouse at the top center of the screen (notch area) to reveal the panel. Move away to collapse. Add your OpenAI API key in Settings for AI chat.
