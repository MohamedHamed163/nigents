How It Works
Three steps to an always-awake Mac
01

Pick a Mode

Choose between mouse jiggle, key press, both, or scroll pulse. Each has its own advantages.

02

Set Interval

Choose how often GhostTouch acts: every 15 seconds up to 5 minutes. Default is 30 seconds.

03

Press Start

GhostTouch runs silently in the background. Your Mac stays awake for downloads, renders, and presentations.

Installation
Get up and running in seconds

Quick Install

# 1. Open the DMG and drag to Applications
$ open GhostTouch.dmg

# 2. Fix quarantine (unsigned app)
$ xattr -cr /Applications/GhostTouch.app

# 3. Re-sign the app
$ codesign --force --deep --sign - /Applications/GhostTouch.app

# 4. Launch!
$ open /Applications/GhostTouch.app

No accessibility permission needed. GhostTouch uses CGEvent to simulate input at the system level.
