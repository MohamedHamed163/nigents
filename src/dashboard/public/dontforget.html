Track 5 Apps

Custom Threshold

Set the idle window anywhere from 30 seconds up to 10 minutes. You decide when to be nudged.

How It Works

Three Steps to Never Forget an App

01

Open & Configure

Launch DontForget. Add up to 5 apps using the file picker. Set your idle threshold with the slider.

02

Close the Window

The menu-bar pill keeps monitoring in the background. Close the config window — it keeps running.

03

Get Reminded

When a tracked app sits idle past the threshold, a glass card drops from the notch with the app icon and a reminder.

Install

Get Started in Seconds

Quick Install

# 1. Open the DMG and drag DontForget to Applications
$ open DontForget.dmg

# 2. Remove the quarantine flag (unsigned build)
$ xattr -cr /Applications/DontForget.app

# 3. Ad-hoc re-sign so macOS opens it
$ codesign --force --deep --sign - /Applications/DontForget.app

# 4. Launch
$ open /Applications/DontForget.app

Uses NSWorkspace to detect app switches. No accessibility permissions needed.
