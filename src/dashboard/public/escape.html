Escape — don't get caught slacking

One hotkey flips every window to VS Code and Terminal in under 100 ms. Part of our Crazy apps line — playful utilities, not enterprise fleet tooling.

What you get

Escape watches for a single hotkey. When pressed, it hides whatever you're doing and surfaces your "work" apps instantly. Release to restore.

Instant window flip

Every visible window hides and VS Code + Terminal come forward in under 100 ms. Faster than your manager can focus.

Configurable trigger

Bind any hotkey or modifier combo. Default is ESC but you can use F13, Caps Lock remap, or a custom shortcut.

Smart app roster

Choose which apps to show (VS Code, Terminal, Xcode) and which to hide (Slack, Discord, YouTube). Fully customizable.

Restore on release

Hold mode: apps restore when you release the key. Toggle mode: press once to flip, press again to restore. Your call.

Zero footprint

No dock icon, no menu bar clutter. Runs silently in the background until you need it.

Fake typing mode

Optional: after flipping, Escape types random code characters into Terminal for 3 seconds. Maximum plausible deniability.

Install

Open the disk image, drag Escape.app into Applications, then eject the volume.

  • If Gatekeeper blocks: System Settings → Privacy & Security → Open anyway.
  • If needed: xattr -cr ~/Downloads/Escape-1.0.0.dmg then open again.
  • Grant Accessibility permission when prompted (required for window management).
